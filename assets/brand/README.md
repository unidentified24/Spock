# Spock ribbon mark

The app uses app/src/main/res/drawable-nodpi/spock_mark.png for its mark, launch icon and welcome screen. Generated with the built-in OpenAI image generation tool on 2026-10-29, then copied unchanged into the project.

Prompt: Create a standalone app icon for Spock, an independent music app: a bold abstract S formed from a folded sound-path ribbon, coral-orange and warm apricot on very dark aubergine, centered with generous adaptive-icon safe padding. Flat graphic precision, subtle dimensional fold, readable at small sizes. No text, headphones, music note, circle with waves, Spotify resemblance, starship, character or watermark.

The image-generation output was inspected before inclusion. No extracted Spotify fonts or logos are used as Spock branding. The UI font is Montserrat with its OFL license bundled in assets/licenses and APK assets.
