# Spock sound-bars mark

The geometry refines the original Spock 1.7/1.8 mark. One seven-bar silhouette is shared across themes. The Compose mark uses the selected theme accent and secondary colors on its surface. The launcher and splash use neutral light bars on graphite; the Android adaptive icon also supplies a monochrome foreground for supported themed launchers.

Editable SVG: spock-logo.svg. Android foreground: app/src/main/res/drawable/spock_symbol.xml. The artwork fits the centered 66 dp safe area in a 108 dp adaptive-icon viewport. No generated metallic bitmap is loaded for app branding.
